# Crosshair Overlay Studio (Estilo Crosshair X)

[English Version](./README.en.md)

> **Linguagem / Stack:** `C# (.NET Framework 4.8 WinForms + Win32 Overlay)` | **Autor:** `piercer`

## O que faz

Overlay nativo de mira customizável para Windows, leve e sem interferência em jogos (janela `TopMost` transparente e **click-through** via `WS_EX_TRANSPARENT`).

- **Estilos variados:** `Cross`, `Dot`, `Circle`, `CrossCircle`, `TShape` e `XCross`.
- **Presets prontos:** CS2 Clássica, Valorant Dot, T-Shape Pro, Apex/Circle e X-Cross.
- **Customização em tempo real:** comprimento, espessura, abertura central (gap), ponto central, contorno preto (outline), cor, opacidade, ajuste fino X/Y e seleção de monitor.
- **Atalhos globais:**
  - `F8`: Liga/desliga a mira instantaneamente.
  - `F9`: Abre/oculta a janela do editor (também acessível pela bandeja do sistema / System Tray).
- **Persistência automática:** salva suas configurações em `crosshair_config.ini`.

## Como executar / compilar

Execute diretamente o binário compilado `piercer_crosshair_overlay.exe` ou recompile com:

```bat
build.bat
```
